# ChillSnap Social

Build ChillSnap - mix of Instagram + Snapchat. Dark aesthetic theme with purple-pink gradient. Features: Instagram style feed with likes/comments/share, stories on top, reels section. Snapchat style: disappearing 24hr snaps, snap streaks with fire emoji, fun filters button, chat with disappearing messages, snap map. Profile username Anamika22 with Bitmoji style avatar. Features: post, story, snap, chat, block/hide/report, private account. Use Supabase for auth and storage. Make it fully functional, modern and addictive.
